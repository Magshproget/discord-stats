# Discord Lifetime Statistics & Data Package Analyzer 📊

Автономний веб-додаток для глибокого аналізу офіційного архіву даних Discord (**Discord Data Package / GDPR export**). 

Увесь парсинг та підрахунок метрик виконується **100% локально у вашому браузері** через Web Streams та вбудовану потокову бібліотеку розпакування. Жоден байт даних не надсилається на сервери.

---

## 🚀 Що аналізує додаток:

### 1. Голосові канали (Voice Activity)
* **Загальний час у войсі:** точна сумарна кількість годин і діб, проведених у голосових каналах за всі роки.
* **Сесії:** кількість підключень, середня тривалість дзвінка та рекордний за тривалістю войс.
* **Динаміка за роками:** річний графік голосового часу (2017 — до сьогодні).
* **Розподіл за днями тижня:** визначення найактивніших днів для розмов.

### 2. Ігрова статистика (Rich Presence & Game Telemetry)
* **Рейтинг ігор:** список ігор, у яких ви проводили час під час дзвінків у Discord.
* **Години у войсі за грою:** точний час, проведений у кожній окремій грі.
* **Кількість ігрових сесій та роки активності.**

### 3. Час у клієнті Discord (Client Sessions)
* **Загальний час відкритих сесій:** оцінка тривалості роботи клієнта Discord за подіями `session_start` та `session_end`.
* **Відсоток життя акаунту:** частка часу, коли ви були онлайн у Discord.

### 4. Добова активність (00:00 — 23:00)
* **Погодинна гістограма:** наочний графік підключень до голосових каналів і написання повідомлень залежно від часу доби.
* Визначення пікових годин активності та часу відпочинку.

### 5. Повідомлення та чати (Messages)
* **Загальний лічильник:** кількість надісланих повідомлень та сумарна кількість слів.
* **Таймлайн:** дата й час найпершого та останнього надісланого повідомлення в історії акаунту.
* **Топ-25 співрозмовників і каналів:** інтерактивна таблиця з пошуком і часткою від усіх повідомлень.

## 📖 Як отримати свій архів від Discord:

1. У лівому нижньому кутку Discord натисніть шестірню **⚙️ Налаштування користувача (User Settings)** поруч з нікнеймом.
2. У лівому меню оберіть розділ **«Конфіденційність та безпека» (Data & Privacy)**.
3. Прокрутіть сторінку донизу до блоку *«Request your data»* та натисніть кнопку **«Request Data» (Запросити дані)**.
4. Оберіть пункти для експорту (для повноти даних рекомендується залишити всі пункти; обов'язкові — **Activity**, **Messages** та **Account**).
5. Discord скомпілює дані та надішле посилання на скачування на вашу пошту (процес зазвичай займає **приблизно 3 дні**).
6. Завантажте отриманий `package.zip` (розпаковувати не потрібно) і перетягніть його у вікно додатку.

## 🔒 Конфіденційність та безпека

* **Zero-Server Architecture:** додаток є статичною HTML-сторінкою без жодного бекенду.
* **Локальна обробка:** розпакування та обробка гігабайтних логів телеметрії відбувається в оперативній пам'яті вашого браузера через стрімінговий двигун.
* **Відкритий вихідний код:** код сторінки відкритий для аудиту.

---

## 🛠️ Стек технологій

* **HTML5 / Modern CSS (Discord Dark Theme)** — адаптивний інтерфейс без сторонніх CSS-фреймворків.
* **fflate (Streaming Unzip)** — надшвидке потокове розпакування ZIP у браузері без зависання сторінки.
* Жодних зовнішніх серверних залежностей чи трекерів.
